## 制作测试变体

1. 准备参考转写 `text`、候选词与音素 `context_text`、目标词 `oov_labels`，格式见 [examples/plain.jsonl](../examples/plain.jsonl)。
2. 提供用于排除已有拼写的词表。若要求替换拼写不在训练词汇中，应将训练词汇纳入排除集合；工具不会自行读取模型训练数据。
3. 选择同步改写转写，或使用 `--context-only` 只改候选。使用 `--targets-only` 可强制改写全部目标；生成失败的记录会被丢弃，需核对输出数量。
4. 在外部运行自己的识别系统，按生成后的 `id` 保存 `hypothesis`，再运行评分器。不同模型应复用相同的已生成数据。

工具会重新生成 ID，且不输出音频路径或原始 ID。需要关联音频时，应自行维护对应关系。复现变体时应保存输入顺序、词表、参数、Python 版本和随机种子。

## 评分口径

评分器按 `misspell_map` 中每条记录的不同 `ORIG->FAKE` 映射计数，并非仅统计 `oov_labels`。若只研究目标词，使用 `--targets-only` 并核对目标范围。

`fake`、`original`、`both`、`neither`、`missing` 为互斥类别；双命中不自动算作替换成功，缺失预测仍计入分母。与论文数值比较前，需统一样本、候选、输出设置、目标定义及分母；本工具不声称已逐项复现论文评分口径。

示例词仅演示格式，不代表论文筛选的 OOV 目标。规则保持输入音素标签，不验证自然发音，也不自动构造错误音素对照。完整字段、命令与规则见[工具说明](data-tools.md)。
